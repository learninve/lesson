# סיירת ניקיון – עריכת רילס אורגנית (`output_reels.mp4`)

```
python3 nikayon_reels/build_reels.py --input <קובץ_מקור_31ש.mp4> --output output_reels.mp4
```
דרישות: `ffmpeg` (libx264), `node` + `playwright`/Chromium (לרינדור הטקסט העברי). הפונט Heebo (OFL) והלוגו נמצאים ב-`assets/`.
את הטקסטים והתזמונים עורכים ב-`layers.json` ומריצים מחדש.

## מה נעשה (הכול נמדד על הקובץ בפועל)
* **כיתוב אנגלי מובנה** – נמצא בשורות y≈110–290 מתוך 1280 (עד ~22.7%), לכן חיתוך של 16% **לא** מכסה אותו.
  הוחלף באנר אטום (480px מתוך 1920 = 25%) בירוק הלוגו עם קו זהב, ובו ההוק בעברית. הטקסט יושב מתחת ל-~200px (Safe Zone).
* **קצב (31.07 → 17.73 שנ', 532 פריימים @30fps)** – מקור→פלט:
  0–2 @1.0x · 2–2.5 @1.2x (רמפה) · 2.5–5 @1.4x · 5–12 @1.6x · 14–22 @1.8x (12–14 נחתך) ·
  22.4–26 @1.8x (=2.0 שנ' בדיוק, כולל הקונסולה) · 28–31 @1.1x (התוצאה הנקייה).
* **צבע** – `eq=contrast=1.10:saturation=1.12` ואחריו `unsharp=5:5:0.5` (luma בלבד), אחרי upscale lanczos 720→1080.
* **טקסט** – Chromium מרנדר RTL אמיתי, Heebo 900, מתאר שחור עבה, מילות מפתח בזהב. תזמון (ציר הפלט): 0–4 הוק · 4–10 משלים · 10–14 מיתוג · 14–סוף CTA.
  ההוק מופיע כבר בפריים הראשון (חשוב לתמונה הממוזערת).
* **כרטיס סיום** (מ-15.0 שנ') – לוגו, "לקבלת הצעת מחיר" ו-055-7718519, מעל המושב הנקי; הכול מעל ~1500px, מחוץ לאזור הממשק התחתון.
* **אודיו** – הדיבור האנגלי (0–2 שנ') שקוע בתוך רעש המנוע ולא ניתן להפרדה; הוחלף ברעש שאיבה נקי מ-3.0–5.1 שנ' המקור (במקום שתיקה מתה בהוק),
  כל קטע האיץ עם `atempo`, כל התפרים בקרוס-פייד שוויון-הספק (בלי "נקישות"), high-pass 35Hz, `loudnorm` דו-שלבי ל-**-14 LUFS**.
* **ייצוא** – 1080x1920, 30fps, H.264 High, CRF 18, preset slow, yuv420p/bt709, AAC 192k/48kHz, faststart.
